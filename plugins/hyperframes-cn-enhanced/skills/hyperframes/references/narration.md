# Narration

Voiceover should make the video easier to understand, not repeat every word on screen.

## Pacing

- Use one strong sentence for fast scenes.
- Use two short sentences only when the scene carries data or a comparison.
- Let generated audio define timing. Do not trim speech to fit a pre-set scene.
- Add about 2 seconds of visual buffer after each measured narration segment.

## Chinese TTS

- Prefer short spoken clauses with clear punctuation.
- Spell out ambiguous numbers or units when needed.
- For edge-tts workflows, generate one audio file per scene and measure with `ffprobe`.
- Keep captions shorter than narration when screen density is high.

## Opening Lines

Good openings state tension immediately:

- "三天摆摊，亏明白了。"
- "这组数据，解释了今天的市场变化。"
- "一篇文章里真正有用的，是这三个信号。"
